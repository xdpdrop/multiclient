## Bugs

- Windows ConPTY script mode never finishes. `script` is test-only; the app opens an interactive shell with `powershell.exe -NoLogo -NoProfile` and no `-Command`. The session test drives `Terminals.open` in script mode. Run [38463852911](https://github.com/xdpdrop/multiclient/actions/runs/38463852911) spawned `-Command -` and PowerShell exited `-196608` because standard input was not redirected. Run [38466011795](https://github.com/xdpdrop/multiclient/actions/runs/38466011795) spawned `-EncodedCommand`, produced no `terminal` data and no `terminal-exit`, recorded exit `-1` after 15s, then hit `EBUSY` deleting the temp directory. The test is skipped on `win32` until this is fixed. [Issue #18](https://github.com/xdpdrop/multiclient/issues/18), [`src/runtime/terminals/index.ts`](https://github.com/xdpdrop/multiclient/blob/e36bde9eb11fe80b5833314c71b8b9228dddbe8f/src/runtime/terminals/index.ts), [`tests/unit/terminal-session.test.ts`](https://github.com/xdpdrop/multiclient/blob/e36bde9eb11fe80b5833314c71b8b9228dddbe8f/tests/unit/terminal-session.test.ts). Size: medium.
- Enter in the custom model ID field submits the composer. The field sits inside the message form, so Enter calls `send()` and clears a ready draft instead of only committing the ID. [Pull request #22](https://github.com/xdpdrop/multiclient/pull/22) is open (+25, 2 files: `src/renderer/App.tsx`, `tests/e2e/custom-model.spec.ts`). On `main` the input has no key handler. Size: small.
- Light-theme accessibility evidence capture fails on GitHub-hosted Ubuntu after the contrast check has passed. `page.screenshot()` uses CDP `Page.captureScreenshot` and failed in run [38519715383](https://github.com/xdpdrop/multiclient/actions/runs/38519715383). [Pull request #21](https://github.com/xdpdrop/multiclient/pull/21) is open (+67 / −38, 9 files) and moves evidence shots to `webContents.capturePage()`, with a retry after the first head threw `UnknownVizError` in run [38535915504](https://github.com/xdpdrop/multiclient/actions/runs/38535915504). The 200% zoom check on `main` already uses `capturePage`. [`tests/e2e/accessibility.spec.ts`](https://github.com/xdpdrop/multiclient/blob/e36bde9eb11fe80b5833314c71b8b9228dddbe8f/tests/e2e/accessibility.spec.ts). Size: small.
