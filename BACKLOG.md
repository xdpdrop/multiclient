## Bugs

- Windows ConPTY script mode never finishes. `script` is test-only; the app opens an interactive shell with `powershell.exe -NoLogo -NoProfile` and no `-Command`. The session test drives `Terminals.open` in script mode. Run [38463852911](https://github.com/xdpdrop/multiclient/actions/runs/38463852911) spawned `-Command -` and PowerShell exited `-196608` because standard input was not redirected. Run [38466011795](https://github.com/xdpdrop/multiclient/actions/runs/38466011795) spawned `-EncodedCommand`, produced no `terminal` data and no `terminal-exit`, recorded exit `-1` after 15s, then hit `EBUSY` deleting the temp directory. The test is skipped on `win32` until this is fixed. Draft [pull request #24](https://github.com/xdpdrop/multiclient/pull/24) re-enabled it and still failed after 9 attempts; it was closed and the work is parked in [issue #27](https://github.com/xdpdrop/multiclient/issues/27) (ruled out: a DA1 reply written before connect, a late xterm reply, `-Command -`, and `cmd.exe /c`). [Issue #18](https://github.com/xdpdrop/multiclient/issues/18), [`src/runtime/terminals/index.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/src/runtime/terminals/index.ts), [`tests/unit/terminal-session.test.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/tests/unit/terminal-session.test.ts). Size: medium.

[`tests/contracts/adapters.test.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/tests/contracts/adapters.test.ts). Size: small.
- Windows Job Object kill-on-close tests are `describe.skipIf(process.platform !== 'win32')`. The C# supervisor is not built on Linux or macOS. [`tests/unit/supervisor.test.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/tests/unit/supervisor.test.ts). Size: none (platform gate).
- `tests/e2e/codex.spec.ts` skips unless `MULTICLIENT_LIVE_DESKTOP=1`. Ordinary Playwright reports that one skip. It is an opt-in subscription desktop case and stays out of pull-request CI. [`tests/e2e/codex.spec.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/tests/e2e/codex.spec.ts). Size: large (maintainer account).

[Validation record](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/docs/provider-compatibility/validation.md). Size: large (maintainer account, disposable directories only).
- Windows unit run [38466011795](https://github.com/xdpdrop/multiclient/actions/runs/38466011795) (head `5bbaa77`, during [pull request #19](https://github.com/xdpdrop/multiclient/pull/19)) timed out `tests/unit/attachments.test.ts` “extracts PDF text by page while retaining the original asset” after 11304ms against the 10s Vitest default, with no failed assertion. The next in-process PDF test in that file passed in 13ms. #19 then gave that test a 30s per-test timeout, which is still on `main`, so the flake is masked rather than explained. On `main` the Windows job reports the whole file at 2909–3985ms across eight runs from 2026-10-14 to 2026-10-15 (Ubuntu: 411ms and 691ms in the two runs checked). `pdfjs-dist@6.4.299` `legacy/build/pdf.mjs` synchronously `require`s the optional `@napi-rs/canvas` native addon when it is imported in Node, which text extraction does not use; whether that load is the slow Windows step is unmeasured. Do not raise the timeout further. [`tests/unit/attachments.test.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/tests/unit/attachments.test.ts), [`src/runtime/files/attachments.ts`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/src/runtime/files/attachments.ts). Size: small.

[Pull request #20](https://github.com/xdpdrop/multiclient/pull/20) fixed alert #1 (`http-cache-semantics` 4.3.0, GHSA-ch52-4w7c-c8xp) and left alert #2 alone; alert #1 is `fixed`. Document only. Do not bump. Size: none until upstream publishes a fix.

## Ideas needing Marek's decision

Listed only. These are release gates and the no-go zones in [AGENTS.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/AGENTS.md). This backlog does not schedule them.

- Public Code and Bypass stay gated until provider, version, and OS certification is recorded. Known Windows Codex 0.158.0 is read-only on the public matrix. Development opt-in is `MULTICLIENT_DEVELOPMENT_MODES=1`. [Provider compatibility](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/docs/provider-compatibility/README.md). Size: large.
- Signing and notarization stay outside the repo. CI publishes an unsigned Windows x64 zip (`Multiclient-win-x64.zip` with `SHA256SUMS.txt`) as a prerelease for `v*` tags. [AGENTS.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/AGENTS.md), [`.github/workflows/ci.yml`](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/.github/workflows/ci.yml). Size: large.
- No auto-update. Do not add `electron-updater`, a publish feed, or a startup update check. `electron-builder.yml` keeps `publish: null`. [AGENTS.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/AGENTS.md). Size: large.
- Credential storage stays in `src/main/secrets.ts`: OS `safeStorage` when a real backend exists, and Linux `basic_text` stays in process memory only. CLI subscription credentials stay with the official CLIs and are rejected by `Secrets.set`. [AGENTS.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/AGENTS.md), [SECURITY.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/SECURITY.md). Size: large.
- Usage is reported, not billed. Codex limit parsing, remaining-percent display, comparison consent, and which billing source a connection uses stay as they are unless Marek changes that policy. [AGENTS.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/AGENTS.md). Size: medium if the policy changes.
- Product name, voice, theme, icons, and visible strings are intentional. A restyle or copy swap needs an explicit decision. [AGENTS.md](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/AGENTS.md). Size: medium to large.
- Importing external native CLI or web histories, multi-account endpoint profiles, cloud sync, and mobile access are deferred. [Implementation status](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/docs/implementation-status.md). Size: large.
- Autonomous provider routing and unattended scheduling are deferred. [Implementation status](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/docs/implementation-status.md). Size: large.
- Office/OCR, automatic RAG, authenticated or intranet research, interactive artifacts, native CLI images, and arbitrary compatible-endpoint vision are deferred. [Implementation status](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/docs/implementation-status.md), [provider compatibility](https://github.com/xdpdrop/multiclient/blob/dd0dcd207bccbad5712508050c8213e6e3644f35/docs/provider-compatibility/README.md).
